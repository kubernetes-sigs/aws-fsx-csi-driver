# Driver Options
There are a couple of driver options that can be passed as arguments when starting the driver container.

| Option argument             | value sample                                      | default                                             | Description                                                                                 |
|-----------------------------|---------------------------------------------------|-----------------------------------------------------|---------------------------------------------------------------------------------------------|
| endpoint                    | tcp://127.0.0.1:10000/                            | unix:///var/lib/csi/sockets/pluginproxy/csi.sock    | The socket on which the driver will listen for CSI RPCs                                     |
| extra-tags                  | key1=value1,key2=value2                           |                                                     | Tags added to every AWS resource the controller creates. Not used to find, filter or isolate resources, and not the cluster tag. A StorageClass `extraTags` value overrides these for the same key. Neither can override `CSIVolumeName`, `fsx.csi.aws.com/cluster` or the `cluster-tag-key` key |
| cluster-name                | my-cluster                                        |                                                     | Name of the cluster: the value of the cluster tag. See [Cluster tag isolation](cluster-tag-isolation.md) |
| cluster-tag-key             | eks:eks-cluster-name                              |                                                     | Key of the cluster tag. Empty writes no cluster tag |
| cluster-tag-isolation       | enforce                                           | disable                                             | `disable`, `backfill` or `enforce`. Set this to match the IAM policy attached to the controller. `backfill` and `enforce` require `cluster-name` and `cluster-tag-key` |
| logging-format              | json                                              | text                                                | Sets the log format. Permitted formats: text, json                                          |
